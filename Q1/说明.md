## 模型要点

- 决策变量 `q, c, d, e, w`（各 144 维）；SOC `E_t` 由累计充放推出，不单列变量。
- 目标 `min Σ p_t·q_t + 5·p_t·e_t`；约束为供需平衡等式 + `1200 ≤ E_t ≤ 10800` + 单区间充放上限 833.33 kWh + 日周期闭合 `E_144 = E_0 = 6000`。
- 用 PuLP + CBC 建 big-M（=833.33）互斥 MILP 校验：LP 最优与 MILP 最优一致（`rel_gap = 0`），且不存在同区间同时充放的退化解。
