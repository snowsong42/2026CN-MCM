# Q0_论文修订图 / 跨问（论文级）图表

本目录是 MHAgent 最新版工作区中**不属于任何单一问题**的成图脚本的独立拷贝：
`gen_revision_figures.py` 一次运行会同时产出问题一的套利图与可行域图、问题二的
两张热力图、典型日画像，以及两张论文级流程图/路线图，因此**不放进 Q1–Q4 任何一问**
（否则要么重复拷 7.6 MB 的结果 json，要么让某一问的 `figures/` 混入别问的图）。
它依赖 `problem_1_results.json` 与 `problem_3_results.json`、以及工作区根的
`result1.xlsx`，所以单独成目录最干净。

## 运行

```powershell
cd "D:\project\pythonProject\2026CN-MCM\Q0_论文修订图"
D:\project\pythonProject\2026CN-MCM\.venv\Scripts\python.exe figures\gen_revision_figures.py
```

只要其中 4 张（典型日、可行域、路线图、流程图），跳过套利图与两张热力图：

```powershell
D:\project\pythonProject\2026CN-MCM\.venv\Scripts\python.exe figures\gen_revision_figures.py --requested-only
```

## 脚本自带的校验（不通过就报错，不会静默出图）

1. `problem_1_results.json` 里的 `series` 与 `附件1.xlsx` 三列**逐点相等**（`atol=1e-8`）。
2. `result1.xlsx` 第 1 张表的计划购电量与 `series['q']` 最大差 ≤ 5.01e-5 kWh（即 6 位小数的舍入容差）。
3. `result1.xlsx` 第 2 张表的 6 段充放电汇总与 `series` 按 4 小时分块求和一致。
4. `附件2.xlsx` 两张表都是 (365, 144)、全有限、日期唯一且逐日连续；月份×星期的样本数合计 365。

各月各星期样本数区间，以及 5 个输入文件的 sha256）。

## 与其它目录的关系

- **不受"配色随目录名漂移"影响**：该脚本不使用 `_figcommon` / `_utils/plot_utils.py`，
  而是自己设 `rcParams`（`Microsoft YaHei`）并硬编码 4 个颜色
  （`#3C5488` 蓝 / `#00A087` 青 / `#E64B35` 红 / `#E3B45A` 金），因此在任何机器、任何
  目录下运行，配色都一致（只要求装有 Microsoft YaHei，否则回退） 。
- 它**取代**了 `workspace/figures/` 里 `gen_fig_typical_day_profile.py` 与
  `gen_fig_q1_arbitrage.py` 的旧设计（见脚本顶部 docstring），但旧脚本仍在工作区保留。
- 其余 5 个跨问脚本（`gen_fig_data_overview.py`、`gen_fig_forecast_method_cmp.py`、
  `gen_fig_sensitivity_tornado.py`、`gen_fig_soc_year_trace.py`、`gen_fig_typical_day_profile.py`）
  仍留在 `workspace/figures/`，需要的话也可以一并搬进来。
