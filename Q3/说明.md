## 模型要点

1. **信息结构**：每天在 **{0, 6, 12, 18}** 四个节点接入未来 24 小时整点光伏预报，把整点预报分段线性降尺度到 144 个 10 分钟区间，日照窗口外钳零。
2. **多阶段滚动（SMPC）**：每个节点基于**该时刻及更早**的预报重解剩余时域的购电计划，只执行到下一节点；已执行时段冻结，构成"滚动时域 + 只推进当前决策"的模型预测控制。
3. **非对称结算（三段式）**：最终账单 = 基准承诺费（按 `min(计划, 调整)` 计）+ 增购费（超出部分 ×1.5）+ 减购违约费（低于部分 ×(0.5−ρ)）+ 紧急购电费（×5）。
   - 主口径 **ρ = 0**（减购不退费）：此时减购既省不下已付计划费、又要交违约金，模型**经济上从不主动减购**，故违约费/减购量恒为 0——这是正确结果而非缺陷。
4. **预报价值实验（VoF）**：对 8 种节点启用组合（2³）分别全年重跑，比较"全节点"与"全关（仅零点决策）"的总费用差额，量化日内预报的价值。

| 指标 | 数值 |

| 增购量 / 减购量 | 577,746.40 / 0 kWh |
| 紧急购电量 / 弃光量 | 152,324.81 / 1,605,246.86 kWh |

| 退费开关 ρ | 0（主口径） |

> 与 Modex 论文（路径A 14,534,537.60 / 路径B 14,526,523.12 元）不同源：Modex 用"仅零点预报 vs 三次滚动"两条路径作对比，MHAgent 用"四个节点全开 vs 全关 + 2³ 组合"做预报价值实验，**信息结构假设不同**，故总费用相差约 −5.8%。
